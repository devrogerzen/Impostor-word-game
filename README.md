# Impostor Word Game

A social deduction party game where players receive words and must find the impostor through clever clues.

## How to Play

- Each player gets a word (one by one on the same device)
- Most players receive the same word
- One player is the impostor with a different but related word
- Players give clues about their word
- Vote to find the impostor
- If wrong, the impostor can guess the correct word to win

## Features

- 10 categories with 30 word pairs each (300 total combinations)
- 3-10 players support
- Mobile-friendly design
- No installation required - just open and play

## Quick Start

Simply open `index.html` in your browser and start playing!

## Categories

Animals, Food, Professions, Sports, Places, Objects, Transportation, Technology, Music, Movies
